# IBM Data Analyst Capstone Project

Capstone project of the IBM Data Analyst Professional Certificate (Coursera).

## Overview
End-to-end analysis of technology-usage survey data covering programming
languages, databases, platforms, web frameworks, and respondent demographics
(age, education, country). The project spans four phases: data collection,
data wrangling, exploratory data analysis, and visualization with dashboards.

Dataset: Provided by IBM 

## Tools
IBM Cognos Analytics · Python (Pandas, NumPy, Matplotlib, Seaborn, Folium,
SciPy, scikit-learn, Requests, BeautifulSoup)

## Project Phases

**Phase 1: Data Collection**
- Web scraping (BeautifulSoup, requests)
- REST API consumption (JSON processing)
- HTTP requests and response handling

**Phase 2: Data Wrangling**
- Duplicate detection and removal
- Missing value analysis and imputation
- Data normalization (Min-Max, Z-score)
- Data type conversion and validation

**Phase 3: Exploratory Data Analysis**
- Distribution analysis (histograms, box plots)
- Outlier detection (IQR, Z-score methods)
- Correlation analysis (Pearson, heatmaps)
- Categorical variable exploration

**Phase 4: Visualization and Dashboards**
- IBM Cognos Analytics dashboard (3 views, see below)
- Python figures and an interactive Folium map

## IBM Cognos Dashboard
1. **Current Technology Usage**: top 10 languages, top 10 databases,
   top platforms, top web frameworks
2. **Future Technology Trend**: top 10 languages to learn, databases,
   platforms, web frameworks
3. **Demographics**: age distribution, country map, education level,

## Key Findings (from the Cognos dashboard)
- JavaScript is the most used language (count 14,943), followed by SQL (12,602)
  and HTML/CSS (12,410). Python ranks fifth (9,590).
- In the "languages to learn" view, JavaScript (11,541) and SQL (10,944) lead,
  followed by TypeScript (10,437). Python is at 8,919 and Rust at 5,597.
- PostgreSQL is the most used database (11,514) and also leads the future
  ranking (12,193). MySQL is second today (8,556). Supabase enters the
  future top 10 (1,623).
- AWS is the largest platform, followed by Microsoft Azure.
- React and Node.js are the leading web frameworks.
- The 25-34 age group is the largest (41.3%), then 35-44 (27.3%).
  Bachelor's degree is the most common education level (8,629), then
  Master's degree (5,000).
